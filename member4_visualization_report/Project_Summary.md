# TSP Branch & Bound 项目总结

## 项目目标
实现并评估**分支定界（Branch & Bound）算法**求解旅行商问题（TSP），与暴力搜索和最近邻启发式算法进行对比分析。

## 核心成果

| 维度 | 结果 |
|------|------|
| **正确性** | B&B在所有测试实例上均找到**最优解**（与暴力枚举完全一致） |
| **剪枝效率** | N=10时剪枝率达 **98.7%**，仅探索1.3%的搜索空间 |
| **速度提升** | N=9时B&B比暴力快 **2.2 倍**；N=10暴力已不可行，B&B仍可在23ms内完成 |
| **启发式对比** | 最近邻运行极快，但解平均比最优差 **2%~10%** |

## 关键结论

1. **B&B是N≤14时可靠的精确求解方法**——在保证最优性的前提下大幅缩小搜索空间
2. **下界剪枝效率随问题规模增大而提升**——城市越多，剪枝收益越显著
3. **N≤6时B&B略慢于暴力**（下界计算开销 > 剪枝收益），**N≥7时开始反超**
4. **N≥10后暴力完全不可行**，而B&B仍可秒级求解

## 局限性

- B&B仍为指数级算法，**N>20后不再实用**
- 当前仅实现了最小边和下界，更紧的下界（如MST、Held-Karp）可进一步提升性能

## 未来方向

- 对比多种下界算法（MST、Held-Karp）的剪枝效果
- 并行化B&B以处理更大规模实例
- B&B + 元启发式（遗传算法、模拟退火）混合策略
